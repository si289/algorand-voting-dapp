# Algorand Voting DApp

## Project Overview

This project is being developed as part of the Algorand course.

The objective of this project is to build a decentralized voting application using the Algorand blockchain.

## Features

- Secure digital voting
- Transparent election results
- Blockchain-based vote storage
- Tamper-resistant records

## Technologies Used

- Algorand Blockchain
- Python
- Git
- GitHub

## Project Status

This project is currently under development and will be updated throughout the course.
